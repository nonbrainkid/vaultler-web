# Промо-ролик The Vaultler (Remotion)

Видео «что такое Vaultler» — как код. Собирается из React-компонентов, рендерится в MP4.

Это **отдельный npm-пакет**, а не часть Next-приложения: рендер-тулчейн (Chrome
Headless ~110 МБ, esbuild) не должен попадать в зависимости сайта и в сборку Vercel.

## Команды

```bash
cd video
npm install
```

```bash
npm run studio
```
Открывает Remotion Studio — таймлайн, превью, перемотка по кадрам. Правки в `src/`
подхватываются на лету. Самый быстрый способ подгонять тайминги.

```bash
npm run render          # 1920×1080 → out/vaultler-16x9.mp4
npm run render:vertical # 1080×1920 → out/vaultler-9x16.mp4
npm run render:square   # 1080×1080 → out/vaultler-1x1.mp4
npm run render:all      # все три подряд
npm run still           # постер-кадр → out/poster.png
```

Один кадр для быстрой проверки вёрстки, без полного рендера:

```bash
npx remotion still VaultlerVertical out/check.png --frame=900
```

## Что где

| Файл | О чём |
|---|---|
| `src/copy.ts` | **весь текст ролика** — правки формулировок только здесь |
| `src/VaultlerVideo.tsx` | монтаж: порядок сцен, длительности, переходы |
| `src/Root.tsx` | три композиции (16:9, 9:16, 1:1) |
| `src/layout.ts` | юнит `u` и флаг `vertical` — одна вёрстка на все форматы |
| `src/theme.ts` | палитра, снятая с `app/globals.css` |
| `src/scenes/*` | сцены по одной на файл |
| `src/components/SafeSprite.tsx` | пиксельный сейф, порт `app/components/SafeSprite.tsx` |

## Правила, которые легко нарушить

**Цифры в ролике обязаны совпадать с ядром игры.** Стрик-множитель — `1 + streak × 0.2`
(`GAME.STREAK_STEP` в `lib/game.ts`), ским рейдера — 15% (`GAME.SKIM`), лестница холда —
`HOLDER_TIERS` (×1 … ×5 по доле в эмиссии), доля места N в пуле — `(11 − N)/55`
(`lib/payout.ts`). Ролик, обещающий больше игры, — это претензия в комментариях, а не
косметика. При правке баланса пройтись по `src/copy.ts` и `src/scenes/Step.tsx`.

**Гардрейлы копирайтинга те же, что на сайте** (CLAUDE.md, инвариант 6): не обещаем APY,
не намекаем на депозиты и кастодию, пул называем призом за место в игре, а не дивидендом
на холд.

**Никаких `Math.random()` и `Date.now()` в сценах.** Рендер идёт параллельными воркерами
по кадрам вразнобой: недетерминированное значение даст дрожащую картинку. Псевдослучайность —
через хеш от индекса (см. `rnd()` в `Backdrop.tsx`), анимация — только от `useCurrentFrame()`.

**Знак `×` не писать в тексте под VT323.** В шрифте нет глифа U+00D7, браузер подставит его
из фолбэка и в кадре появится надстрочная закорючка. В Press Start 2P (`PIXEL`) `×` есть.

## Звука нет

Дорожка не добавлена намеренно: подбор музыки — лицензионный вопрос, а не технический.
Когда трек будет, положить его в `public/` и добавить `<Audio src={staticFile("...")} />`
в `VaultlerVideo.tsx`.
