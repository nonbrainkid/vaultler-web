# Фронтенд: страница и компоненты

React 19 + Next 16 App Router. Стили — `app/globals.css` (см. `docs/design.md`).
Серверные компоненты по умолчанию; `"use client"` только там, где есть состояние.

## Структура лендинга (`app/page.tsx`)

```
SiteHeader                      клиентский: сессия, коннект, бургер
main
  Hero            #top          заголовок, слоган, CTA (PLAY / BUY $VLTR — заглушка), соцсети
  HowItWorks      #how          4 шага + SkinShowcase + полоса тиров
  GameSection     #game/#board  Vault + Leaderboard (клиентская обёртка с общим состоянием)
  TokenSection    #token        ×5 за холд, пул из фисов, fair launch, флайвил, «что мы НЕ делаем»
  TrustSection    #trust        3 карточки доверия + «честный статус» (live/soon/not yet)
  Faq             #faq          9 вопросов в <details>
SiteFooter                      бренд, соцсети, дисклеймеры
```

`export const dynamic = "force-dynamic"` на странице — обязательно: статический HTML не
может получить per-request CSP-nonce (см. `docs/security.md`).

## Клиентские и серверные компоненты

| Компонент | Тип | Роль |
|---|---|---|
| `Hero`, `HowItWorks`, `TokenSection`, `TrustSection`, `Faq`, `SiteFooter`, `Socials` | server | статический контент и копирайтинг |
| `SiteHeader` | client | `useSession()`, `ConnectButton`, бургер (Esc + блок скролла) |
| `GameSection` | client | общий стейт игры и борда |
| `Vault` | client | игровой экран |
| `Leaderboard` | client | борд, поллинг, отдаёт ранг наверх |
| `ConnectButton` | client | wagmi, SIWE, модалка выбора кошелька, смена сети |
| `ProfileEditor` | client | ник + переключатель приватности адреса |
| `SkinShowcase` | client | витрина скинов (нужен размер комьюнити) |
| `SafeSprite` | server | чистая отрисовка спрайта по уровню |

`Providers` (`app/providers.tsx`) — `WagmiProvider` + `QueryClientProvider`,
`QueryClient` создаётся через `useState`, чтобы не пересоздавался на ререндерах.

## Поток состояния

```
GameSection  ─ rank, players ─►  Vault ──► SafeSprite (скин)
     ▲                            │
     └── onRank ── Leaderboard ◄── onStackChanged (кранк → перечитать борд)
```

Ранг считает сервер (`/api/leaderboard`) — `GameSection` держит его и отдаёт в игру,
чтобы не пересчитывать скин на каждом опросе состояния.

## Vault.tsx — игровой экран

Поллинг `/api/state` раз в **2.5 с**, плюс немедленный refetch на `visibilitychange`
(вернулся на вкладку — увидел актуальное). Кранк — `POST /api/crank`, ответ применяется
тем же `applyResponse`, что и опрос.

**Плавность между поллами.** Локальный таймер (250 мс; 1 с при reduced-motion)
экстраполирует стек: `stack + ratePerSec × min(elapsed, доКонцаОкна)`. Это чистая
косметика — на следующем ответе сервера значение затирается серверным. Экстраполяция
ограничена концом окна завода, чтобы цифра не убегала за реальное начисление.

Что рисуется:
- **tierbar** — текущий тир и следующий порог;
- **машина**: спрайт сейфа + камера с монетами (`coinCount` — от прогресса внутри тира,
  капы `COIN_CAP`), падающие монеты `.drop` не чаще одной в 520 мс;
- **ридауты** STACK / STREAK / ×MULT и SVG-шкала множителя (нормировка до ×15);
- **статус** фазы (`role="status"`) и кнопка кранка с меняющимся лейблом:
  `CRANK` / `WINDING…` (disabled) / `RESTART` (danger);
- **вспышка рейда** — только если `raid.lost > 0` и не включён reduced-motion;
- **боковая панель**: HOLDER BOOST (или CONNECT), `ProfileEditor` при подключённом
  кошельке, THE RULES.

## Обработка сетевых ошибок

Принцип: **последнее состояние остаётся на экране**, сверху — честный баннер.
Белого экрана и обнуления цифр быть не должно — игрок решит, что стек потерян.

- `Vault`: `.netbanner` «Can't reach the machine. Your stack is safe on the server» + RETRY;
- `Leaderboard`: `.lb-err` «showing the last snapshot», старые строки остаются;
  до первой загрузки — skeleton-строки;
- `SkinShowcase`: пока размер комьюнити неизвестен (`players === null`) не показывает
  ни замки, ни открытые скины — иначе мигнёт неверным состоянием;
- границы ошибок: `app/error.tsx` (секции), `app/global-error.tsx` (падение layout,
  собственная разметка без зависимостей темы), `app/not-found.tsx`.

## ConnectButton — три состояния

1. **не подключён** → `CONNECT` → модалка со списком коннекторов (дубликаты EIP-6963
   отфильтрованы по имени);
2. **подключён, не подписан** → `SIGN IN` (SIWE-флоу) + «✕» для disconnect;
3. **подключён и подписан** → короткий адрес → модалка с полным адресом,
   «ADD / SWITCH TO ROBINHOOD CHAIN» и DISCONNECT. При неверной сети — кнопка `WRONG NET`.

Отказ подписи в кошельке ошибкой **не считается** (это просто отмена) — сообщение
не показывается: `/reject|denied|User rejected/i` фильтруется.

## Leaderboard.tsx

Поллинг раз в **8 с** + на `visibilitychange` + при изменении `refreshKey` от родителя
(после кранка стек изменился). Показывает общий сейф, число стакеров, отсчёт до конца
недели, зону выплат («ranks 1–10 are in the money»), подсветку `you` и отдельную строку
«you — N off the top 10», если игрок вне топа.

Приватность на клиенте: если `label` уже равен короткому адресу — не дублируем его,
показываем только кликабельную ссылку в explorer (`NEXT_PUBLIC_RH_EXPLORER`).
Без explorer в env адрес отображается текстом, без ссылки. Боты помечены тегом `test`.

## Копирайтинг: гардрейлы

Тексты — часть безопасности продукта, менять осторожно:
- **никакой токеномики по бакетам** (fair launch: нет тим-аллокации, пресейла, казны);
- **не держим средства пользователей** — нигде не намекать на депозиты/стейкинг-контракт;
- **никогда не называть цифру APY/доходности**; `$STACK` — игровой счёт без ценности;
- пул — **приз за место в игре**, а не дивиденд на холд (юридически важно,
  см. `docs/leaderboard-rewards.md`);
- секции «WHAT WE DO NOT DO» и «HONEST STATUS» проговаривают ограничения прямо.
  Если что-то из написанного перестало быть правдой — это баг, а не мелочь.
